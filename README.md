## Overview

VVT is a browser-based application designed around the daily reality of a technical and operational team in a thermal spa environment.

The project began with a practical observation: operational information only creates value when it can be entered quickly, shared with the right people and found again when it matters. VVT brings essential field workflows into one coherent, role-based experience.

This repository presents the **product journey and the skills demonstrated**. It is not the application's source-code repository.

## The challenge

Daily operations involve several roles, recurring actions, time-sensitive checks and records that must remain understandable over time. A useful solution therefore had to:

- work naturally on both mobile and desktop;
- reflect actual responsibilities rather than impose a generic workflow;
- make important actions visible without overwhelming users;
- preserve a clear operational history;
- evolve as teams identified new needs.

The public description is intentionally high-level. VVT includes:

## Product approach

1. **Observe the work** — understand the task, the environment and the person performing it.
2. **Define the useful information** — remove duplication and clarify responsibility.
3. **Build a testable workflow** — favour clarity and field usability.
4. **Test with users** — compare the design with real working conditions.
5. **Improve continuously** — treat feedback as product input, not as an afterthought.

## Outcome

VVT moved from an internal idea to a tool used in day-to-day operations.

Its value is primarily qualitative:

- one shared operational reference;
- clearer ownership and follow-up;
- less fragmented information;
- better visibility of pending or missing actions;
- a growing history that supports continuity;
- faster iteration between an identified problem and a usable improvement.
